# TicketPro

Приложение для продажи билетов на рейсы (курсовая работа по программной инженерии).

Возможности: поиск рейсов по направлению, просмотр информации о рейсе, бронирование и оплата билета, история заказов.

Технологии: C#, Windows Forms, .NET Framework 4.8, Visual Studio 2022.

Запуск: открыть `TicketPro.sln` в Visual Studio и нажать F5.
